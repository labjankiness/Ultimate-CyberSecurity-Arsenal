# IoT-Network-Honeypot

A lightweight IoT honeypot to monitor and log network attacks on home systems.

## Features
- Listens on common IoT ports (80, 8080, 554, 23).
- Logs connection attempts and payloads.
- Multi-threaded handling.

## Usage
```bash
python honeypot.py
```
Check `logs/honeypot.log` for activity.
