# Ransomware-Simulation-Lab

Educational ransomware simulation environment for studying cryptographic attacks and defense.

## Contents
- `lab.py`: AES-128 CFB encryption script.
- `decrypt.py`: AES-128 CFB decryption script.
- `/sandbox`: Target folder for simulation.

## Usage
1. Place files in `sandbox/`.
2. Run `python lab.py` to simulate encryption.
3. Run `python decrypt.py` to restore files.
